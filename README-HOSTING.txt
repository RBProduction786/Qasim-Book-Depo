FREE HOSTING USING YOUR BROWSER (GitHub Pages)
1. Go to https://github.com and sign in or create an account.
2. Click + (top right) > New repository. Name it qasim-book-center-site. Choose Public and create it.
3. Open the new repository > Add file > Upload files.
4. Upload the index.html file and the assets folder from this extracted folder. Do not upload only the ZIP.
5. Click Commit changes.
6. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a few minutes; GitHub Pages will display your live website URL on the Pages settings page.
9. Keep index.html and assets folder together; the product photos depend on assets.

The GitHub Pages URL is public. Free hosting does not include a custom domain, payment gateway, admin panel, or live inventory database.
